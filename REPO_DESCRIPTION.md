## How to Set Description (如何设置描述)

1. Go to your repository on GitHub
2. Click the ⚙️ gear icon near "About" section
3. In the "Description" field, paste one of the descriptions above
4. Add topics/tags in the "Topics" field
5. Check "Website" if you have a demo site
6. Click "Save changes"
