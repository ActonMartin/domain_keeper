# Images 目录

此目录用于存放项目相关的图片资源。

## 📁 目录结构

```
images/
├── wechat-pay.png      # 微信收款码
├── alipay-pay.png      # 支付宝收款码
└── README.md           # 本说明文件
```

## 📝 使用说明

### 添加收款码

1. **准备收款码图片**
   - 微信：打开微信 → 我 → 服务 → 收付款 → 二维码收款 → 保存图片
   - 支付宝：打开支付宝 → 收付款 → 收钱 → 保存图片

2. **重命名图片**
   - 微信收款码重命名为 `wechat-pay.png`
   - 支付宝收款码重命名为 `alipay-pay.png`

3. **放置图片**
   - 将图片放到此 `images` 目录下

4. **提交到仓库**
   ```bash
   git add images/wechat-pay.png images/alipay-pay.png
   git commit -m "docs: 添加收款码图片"
   git push
   ```

### 图片要求

- **格式**: PNG 或 JPG
- **大小**: 建议不超过 500KB
- **尺寸**: 建议正方形，如 300x300 或 400x400
- **清晰度**: 确保二维码清晰可扫描

## ⚠️ 注意事项

1. **隐私保护**
   - 收款码是公开的，任何人都可以扫码付款
   - 不会泄露个人敏感信息（如银行卡号）

2. **安全性**
   - 收款码只能收款，不能扣款
   - 相对安全可靠

3. **可选性**
   - 收款码是可选的
   - 如果不想添加，可以删除 DONATE.md 中的图片引用
   - 或者只保留一种支付方式
